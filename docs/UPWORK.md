# RelayDesk: Reliable Order Sync & Webhook Integration

Role: Backend & Full-Stack Developer | Go, C++, TypeScript, PostgreSQL

Order synchronization service with a Go API and delivery worker, C++ total validation, a TypeScript dashboard, and a durable PostgreSQL outbox. Handles signed webhooks, duplicate events, versioned updates, retries, manual recovery, and audit history. Includes a fulfillment simulator for outage and lost-reply demonstrations, plus a Stripe test-webhook adapter. Personal project with Docker setup and automated reliability checks.

Skills: Golang, C++, TypeScript, PostgreSQL, Docker
